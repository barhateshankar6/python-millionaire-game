# Python Millionaire Game

A simple command-line quiz game inspired by *Kaun Banega Crorepati (KBC)*.

## Features

- Multiple-choice questions
- Prize money after each correct answer
- Game ends on the first wrong answer
- Beginner-friendly Python project
- Uses lists, loops, conditions, and user input

## Technologies Used

- Python 3

## How to Run

1. Clone the repository

```bash
git clone https://github.com/your-username/python-millionaire-game.git
```

2. Open the project folder

```bash
cd python-millionaire-game
```

3. Run the program

```bash
python millionaire_game.py
```

## Example

Question:
Who is Shah Rukh Khan?

a. WWE Wrestler
b. Plumber
c. Actor
d. Astronaut

Choose number:
3

Output:
Correct Answer
